# Стартовый промт для Claude Code

Скопируй и вставь этот текст в Claude Code, запустив его прямо в папке `almatn` (после того как туда положены `CLAUDE.md` и этот проект инициализирован в git).

---

```
Прочитай CLAUDE.md в корне этого репозитория — это полное техническое задание проекта almatn (Telegram-бот для заучивания текстов по системе интервального повторения).

Сделай следующее:

1. Войди в plan mode. Предложи мне: (а) финальную структуру папок, (б) финальную Prisma-схему на основе раздела 4 CLAUDE.md, (в) порядок этапов реализации. Дождись моего подтверждения, прежде чем писать код.

2. После подтверждения — реализуй проект по этапам из раздела 6 CLAUDE.md, начиная с этапа 1 (каркас). После каждого этапа останавливайся, кратко резюмируй, что сделано и как это проверить руками (например, "запусти npm run dev, отправь боту /start, должен ответить..."), и жди, прежде чем переходить к следующему этапу.

3. Бизнес-логику (расчёт дневной нормы, расчёт дат повторов) пиши как чистые функции в src/core/, без зависимости от Telegram и без обращения к БД напрямую — и сразу покрывай их юнит-тестами.

4. Для планировщика используй устойчивую к перезапуску схему: все даты напоминаний хранятся в БД (таблица Review), а не в setTimeout/памяти процесса. Отдельная cron-задача каждые несколько минут проверяет, что "созрело", и отправляет.

5. Секреты (токен бота, строка подключения к БД) — только через .env, добавь .env.example с плейсхолдерами и .gitignore.

6. Не реализовывай Mini App/веб-интерфейс сейчас — только заложи архитектуру так, чтобы это было легко добавить позже (см. раздел 2 и 7 CLAUDE.md).

Начни с шага 1 — предложи план структуры и схемы данных, прежде чем писать какой-либо код.
```

## Что нужно подготовить до этого

1. **Токен бота** — напиши в Telegram [@BotFather](https://t.me/BotFather), команда `/newbot`, следуй инструкциям, сохрани токен.
2. **PostgreSQL** — либо локально (`brew install postgresql` на Mac), либо через Docker (`docker run --name almatn-db -e POSTGRES_PASSWORD=... -p 5432:5432 -d postgres`).
3. **Node.js** — уже установлен (проверено).
4. Когда Claude Code спросит про `.env` — впиши туда токен бота и строку подключения к БД (сам Claude Code не должен видеть токен нигде, кроме `.env`, который в git не попадает).

## После MVP — если решишь делать Mini App

Просто дай Claude Code команду в духе:

```
Прочитай CLAUDE.md заново. Теперь реализуй этап 8 — Telegram Mini App: добавь webapp/ (React + Vite) с экраном чтения текущей порции текста и экраном прогресса, и src/delivery/api/ с эндпоинтами, использующими существующие src/core/ функции. Авторизация — через Telegram.WebApp.initData.
```

Архитектура (core/ отделён от delivery/) уже готова к этому — переписывать существующую логику бота не придётся.
