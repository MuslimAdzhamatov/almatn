# almatn

Telegram-бот для заучивания текстов (манзумы на арабском с пронумерованными строками) по системе интервального повторения.

- Полное техзадание: [CLAUDE.md](./CLAUDE.md)
- Пошаговый план разработки: [01_plan.md](./01_plan.md)
- Стартовый промт для Claude Code: [02_start_prompt.md](./02_start_prompt.md)

## Быстрый старт

1. Открой этот репозиторий в Claude Code.
2. Вставь промт из `02_start_prompt.md`.
3. Следуй инструкциям — Claude Code сначала предложит план структуры/схемы данных, потом реализует проект по этапам.
